This is code of the experiments and results presented in 'Leveraging Associative Reasoning for Semantic Role Labelling through Multitask Finetuning with Named Entity Recognition in a Small Data Scenario'.


# Code

Folders
- SRL
Contains code to singletask fine-tune (SRL)

- MultiTask
Contains code to multitask fine-tune (SRL and NER)

- lexical_class_similarity_test
Contains the .py file to perform our extra similarity test experiment. Directly prints results.

# Results

Contains all results of our main experiments. Also contains an ipynb file that can be run to easily reproduce the results as reported in the paper
